## 簡介

Zod 是以 TypeScript 為基礎的驗證函式庫。您可以在 Zod 中定義 *架構（schema）*來進行資料驗證，無論資料是簡單的「字串」抑或是複雜的巢狀物件。

```ts
import * as z from "zod";

const User = z.object({
  name: z.string(),
});

// some untrusted data...
const input = { /* stuff */ };

// the parsed result is validated and type safe!
const data = User.parse(input);

// so you can use it with confidence :)
console.log(data.name);
```

## 特色

- 無任何外部依賴
- 可在 Node.js 及所有現代瀏覽器環境中運作
- 體積輕巧：2kb 的核心套件（gzipped 壓縮）
- 不可變（immutable）API：方法會傳回新的實例
- 簡潔的介面（interface）
- 可與 TypeScript 及純 JS 搭配使用
- 內建 JSON 架構（schema）轉換
- 廣泛的生態系統


## 安裝


```sh
npm install zod
```

> Zod 也可以在 [jsr.io](https://jsr.io/@zod/zod) 上以 `@zod/zod` 的形式提供安裝。

Zod 提供了一個 MCP 伺服器，可以讓代理用來搜尋 Zod 的文件。若要新增至編輯器，請參考 [這份指南](https://share.inkeep.com/zod/mcp)。另外，Zod 也提供一個 [llms.txt](https://zod.dev/llms.txt) 檔案。

## 環境需求

Zod is tested against *TypeScript v5.5* and later. Older versions may work but are not officially supported.
Zod 已針對 *TypeScript v5.5* 及更新版本進行測試。較舊的版本可能可以運作，但官方上已不支援。

### TypeScript 嚴格模式（`"strict"`）

You must enable `strict` mode in your `tsconfig.json`. This is a best practice for all TypeScript projects.

```ts
// tsconfig.json
{
  // ...
  "compilerOptions": {
    // ...
    "strict": true
  }
}
```
