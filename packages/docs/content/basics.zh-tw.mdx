本頁將介紹建立架構（schema）、資料解析以及使用型別推論的基本知識。有關 Zod 架構 API 的完整說明文件，請參考 [定義架構（schema）](/api)。

## 定義架構（Schema）

在做其他事之前，您需要定義架構（schema）。在本指南中，我們會以簡單的物件架構做為範例。

<Tabs groupId="lib" items={["Zod", "Zod Mini"]}>
<Tab value="Zod">
```ts
import * as z from "zod"; 

const Player = z.object({ 
  username: z.string(),
  xp: z.number()
});
```
</Tab>
<Tab value="Zod Mini">
```ts
import * as z from "zod/mini"

const Player = z.object({ 
  username: z.string(),
  xp: z.number()
});
```
</Tab>
</Tabs>

## 資料解析

當我們建立了一個 Zod 架構，使用 `.parse` 方法來驗證輸入值。若通過驗證 Zod 會回傳輸入值的帶有型別定義的*深度拷貝*資料。

```ts
Player.parse({ username: "billie", xp: 100 }); 
// => returns { username: "billie", xp: 100 }
```

<Callout>
**Note** - 如果您的架構中使用某些非同步的 API，例如 `async` [refinements](/api#refinements) 或 [transforms](/api#transforms) ，您則需要使用 `.parseAsync()`。

```ts
await Player.parseAsync({ username: "billie", xp: 100 }); 
```
</Callout>

## 處理錯誤

當驗證失敗時，`.parse()` 方法會拋出一個 `ZodError` 實例，其中包含驗證問題的詳細資訊。

<Tabs groupId="lib" items={["Zod", "Zod Mini"]}>
<Tab value="Zod">
```ts
try {
  Player.parse({ username: 42, xp: "100" });
} catch(error){
  if(error instanceof z.ZodError){
    error.issues; 
    /* [
      {
        expected: 'string',
        code: 'invalid_type',
        path: [ 'username' ],
        message: 'Invalid input: expected string'
      },
      {
        expected: 'number',
        code: 'invalid_type',
        path: [ 'xp' ],
        message: 'Invalid input: expected number'
      }
    ] */
  }
}
```
</Tab>
<Tab value="Zod Mini">
```ts
try {
  Player.parse({ username: 42, xp: "100" });
} catch(error){
  if(error instanceof z.core.$ZodError){
    error.issues; 
    /* [
      {
        expected: 'string',
        code: 'invalid_type',
        path: [ 'username' ],
        message: 'Invalid input: expected string'
      },
      {
        expected: 'number',
        code: 'invalid_type',
        path: [ 'xp' ],
        message: 'Invalid input: expected number'
      }
    ] */
  }
}
```
</Tab>
</Tabs>

若不想使用 `try/catch`，您也可以用 `.safeParse()` 方法來取回一個純結果的物件，其中包含成功解析的資料或一個 `ZodError` 實例。結果型別是 [discriminated union](https://www.typescriptlang.org/docs/handbook/2/narrowing.html#discriminated-unions)，因此您可以方便地處理兩種情況。

```ts
const result = Player.safeParse({ username: 42, xp: "100" });
if (!result.success) {
  result.error;   // ZodError instance
} else {
  result.data;    // { username: string; xp: number }
}
```

<Callout>
**Note** - 如果您的架構使用某些非同步的 API，例如 `async` [refinements](/api#refinements) 或 [transforms](/api#transforms) ，您需要使用 `.safeParseAsync()` 方法來取代。

```ts
await schema.safeParseAsync("hello");
```
</Callout>

## 型別推論

Zod 會從您的架構定義中推論出一個靜態型別。您可以使用 `z.infer<>` 工具來萃取這個型別，然後使用在任何地方。

```ts
const Player = z.object({ 
  username: z.string(),
  xp: z.number()
});

// extract the inferred type
type Player = z.infer<typeof Player>;

// use it in your code
const player: Player = { username: "billie", xp: 100 };
```

在某些情境下，架構的輸入值與輸出型別可能會不同。例如，`.transform()` API 可以將輸入值從一型別轉換成另一型別。在這些情況下，您可以獨立抽取輸入和輸出型別：

```ts
const mySchema = z.string().transform((val) => val.length);

type MySchemaIn = z.input<typeof mySchema>;
// => string

type MySchemaOut = z.output<typeof mySchema>; // equivalent to z.infer<typeof mySchema>
// number
```
